## Replacing a figure

- **Same file name, no README edit.** Overwrite the PNG in place, e.g. export the paper's
  architecture diagram as `docs/figures/architecture.png`.
- **Light/dark pairs.** The README loads `*_dark.png` through a `<picture>` element when the
  viewer uses a dark GitHub theme. You can either overwrite both files, or delete the
  `<source … _dark.png>` line in the README so that one image serves both themes.
- **Recommended export.** PNG, about 2400 px wide, with a white or transparent background.
  Any aspect ratio works because the README sets only the width.

## Style used by the generated figures

- System sans (Segoe UI), hairline solid gridlines, 2 px lines, markers with a 2 px surface ring.
- Categorical colours: blue `#2a78d6` / orange `#eb6834` (light), `#3987e5` / `#d95926` (dark).
  They pass the colour-vision-deficiency (CVD) and contrast checks on both surfaces
  (`#fcfcfb` / `#1a1a19`).
- Magnitudes (|Δ| maps) use a single-hue blue ramp with a fixed 0–0.4 scale in both rows.
